# PLITAP · Ядро протокола

Переносимая реализация общих проверок плитки и её операций.

**Этап:** Опубликована структура направления. Реализация и содержательные материалы будут добавляться отдельными изменениями.

[Карта проекта](https://github.com/Plitap/Plitap/blob/main/REPOSITORIES.md) · [Общие правила участия](https://github.com/Plitap/.github/blob/main/CONTRIBUTING.md)

## Назначение

- Чтение и каноническое представление данных, проверка хешей и подписей.
- Проверка полномочий, переходов состояния, правил типов и применимых профилей.
- Повторяемые результаты проверки для одинаковых исходных данных и доказательств.

## Границы направления

Ядро проверяет предоставленные данные и доказательства. Правильная подпись старого состояния сама по себе не подтверждает его актуальность. Доставка относится к [network](https://github.com/Plitap/network), а поддержание распределённого состояния — к [node](https://github.com/Plitap/node).

## Структура

| Раздел | Назначение |
|---|---|
| [`src/`](src/) | Исходный код проверки форматов, подписей, полномочий и переходов. Язык и пакетная структура ещё не выбраны. |
| [`tests/`](tests/) | Внутренние проверки ядра, включая ошибочные данные и недопустимые переходы. |
| [`docs/`](docs/) | Устройство ядра, контракты его функций и инструкции разработки. |

Каждый раздел сейчас содержит README с его назначением. Названия разделов не обозначают готовую функцию или выбранную технологию.

## Участие

Вопросы об этом направлении и конкретные задачи — в [Issues](https://github.com/Plitap/core/issues). Общие идеи — в [обсуждениях PLITAP](https://github.com/Plitap/Plitap/discussions).

Предложение должно объяснять задачу, ожидаемый результат и связанные компоненты. Рабочее обсуждение, принятое правило и опубликованная реализация имеют разные статусы.

## Условия использования

Лицензии для кода, спецификации и визуальных материалов определяются отдельно. См. [статус лицензирования](https://github.com/Plitap/.github/blob/main/LICENSING.md).
